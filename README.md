Agentic AI Chatbot
Overview

This project is a basic chatbot built using agentic AI concepts. The goal was to move beyond simple rule-based or static response chatbots and explore how an agent-driven approach can make conversations more flexible and context-aware.

The chatbot is designed to understand user input, decide how to respond using agent logic, and maintain a simple conversational flow. This project was built primarily for learning and hands-on practice with agentic AI systems.

What This Project Does?

Accepts user input and generates conversational responses

Uses agent-based reasoning to decide how to respond

Maintains basic conversation context across interactions

Demonstrates the fundamentals of agentic AI in a simple, readable implementation

Technologies Used:

- Python

- Agentic AI concepts

- Prompt engineering

= Conversational state handling

Project Highlights:

Built a clean and modular chatbot structure for easy understanding and extension

Applied agent-driven logic instead of hardcoded response rules

Designed the conversation flow to be context-aware and adaptable

Focused on clarity, simplicity, and practical learning rather than over-engineering

How to Run the Project:
# Clone the repository
git clone https://github.com/HarishThupati63/AgenticLanggrap.git

# Navigate to the project folder
cd AgenticLanggrap

# Install required packages
pip install -r requirements.txt

# Run the chatbot
python main.py
